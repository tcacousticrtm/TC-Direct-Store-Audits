🟢 Connect to Google Sheets

1
Open your Google Sheet, then click Extensions → Apps Script
2
Paste the TC_Audit_AppScript.gs code (provided separately), replacing all existing code. Click Save.
3
Click Deploy → New deployment. Set type to Web app, execute as Me, access Anyone. Click Deploy.
4
Copy the Web App URL and paste it below:
⚠ Using a Google Workspace account (e.g. @tcacoustic.com.sg)?
Workspace accounts restrict CORS responses from Apps Script even when access is set to "Anyone". This is normal — your audit data will still reach the sheet correctly. The Test Connection button will confirm your URL is reachable and show a Workspace-mode notice. If "Anyone" is not available and only shows your domain, ask your Google Workspace admin to allow external web app deployments, or use a personal Google account to host the script.

Google Sheet Structure

The script automatically creates two tabs in your sheet:

Tab 1: Audit Results
Saved At · Store Code · Store Name · Audit Date · Audit Month · Audited By · Audit Method · Previous Score · Inspire (%) · Educate (%) · Convert (%) · Overall (%) · Tier · Items Passed · Total Items · Open Actions · Notes
Tab 2: Item Detail
Saved At · Store Code · Audit Date · Auditor · Stage · Sub-section · Item # · Item Description · Result · Feedback / Action Required

Re-saving the same store + date overwrites the existing row (no duplicates).
